Welcome to A-Z+T

A-Z+T (A to Z plus Tone) is a community-based language development tool that helps systematically check a dictionary with respect to consonants, vowels, and tone.

This installer will:

  • Install A-Z+T to your Applications folder
  • Install the Charis SIL font (required for IPA and tone mark display)

A LIFT lexicon file (from FLEx or WeSay) is required to use A-Z+T. You can also start a new database from scratch within the app.

Note: macOS will warn about an unidentified developer since this build is unsigned. To allow it: System Settings → Privacy & Security → Open Anyway.
